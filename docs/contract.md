## Kaiterra API Mapping

- `GET /devices/{device_udid}` is used for device metadata.
- `GET /devices/{device_udid}/top` is used for latest sensor readings.
- The API key is sent as the `key` query parameter.
- `refresh` updates one configured device.
- `sync_cloud` updates all configured devices when no specific config is supplied.

Keep `manifest.json`, `contract.py`, `kaiterra.py`, and route handlers in sync.
